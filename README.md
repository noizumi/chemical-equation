# 化学反応式マスター

中学2年生向けの化学反応式トレーニングゲーム。iPad での使用を想定し、全モードにタイムアタック（グレード評価 SS/S/A/B/C・端末内ベスト記録・復習機能つき）を搭載しています。

## モード

| ステップ | モード | 内容 |
| --- | --- | --- |
| STEP1 | 化学式マッチ | 物質名 ⇔ 化学式の対応づけ（4択 × 20問）。きほん（中2頻出）／チャレンジ（中3・発展） |
| STEP2 | 係数バランス | 反応式の化学式は与えられ、係数だけを入力してつり合わせる（10問）。きほん／チャレンジ |
| STEP3（裏） | ○×ジャッジ | 表示された反応式が正しいか瞬時に判定（20問）。ミスは＋3秒ペナルティ |
| STEP4（裏） | 組み立てラボ | 実験の説明文から、物質カードの選択＋係数入力で反応式をまるごと組み立てる（5問） |

STEP3・STEP4 は**裏モード**：STEP1・STEP2 の全4モード（化学式き／チ・係数き／チ）で S ランク以上のベスト記録をとると解放されます。それまではカードは表示されるもののタップしても反応しません。解放条件を満たした瞬間の結果画面に「裏モード解放！！」のバナーが出て、ホームのバッジが STEP3/4 → 「裏モード」に変わります（あそび方モーダルに解放条件のヒントあり）。

学習支援の仕掛け：

- 係数をまちがえると「原子の数チェック」パネルが出現し、左辺：右辺の原子数が元素ごとにライブ表示される
- つり合っていても最簡整数比でない場合（例 4H₂O → 4H₂ + 2O₂）は専用メッセージで再挑戦を促す
- 正解時は係数1を省略した正式な書き方で完成式を表示
- 結果画面に「まちがえた問題」の一覧（正しい式つき）と復習モード

## 収録データ

「中学範囲で頻出の化学反応式」資料をもとに、イオン反応式（電荷 ⁺/⁻ や e⁻ を含むもの・電池の半反応式）を除いた 44 反応式・57 物質を収録。

- きほん＝中2「化学変化」（化合・燃焼・分解・電気分解・還元）17 式
- チャレンジ＝気体の発生・中和・有機物の燃焼など 27 式
- 資料の「3Fe＋2O₂ → Fe₂O₃」は係数がつり合わないため、正しい「3Fe＋2O₂ → Fe₃O₄（四酸化三鉄）」に修正して収録

### 問題の追加・編集

`src/data.js` だけを編集すれば OK です。

```js
// 物質： f=化学式（ASCII表記）, name=物質名, q=化学式マッチの出題レベル(1/2/0)
{ f: "Ca(OH)2", name: "水酸化カルシウム", q: 2 },

// 反応式： lv=1(きほん)/2(チャレンジ), jd=○×ジャッジ対象, bd=組み立て対象
eq("cu_o2", 1, "酸化", "銅を空気中で加熱する",
  [[2, "Cu"], [1, "O2"]], [[2, "CuO"]], { jd: true, bd: true }),
```

編集後は `npm run validate` で全反応式のつり合い・最簡整数比・物質登録もれを自動チェックできます（係数は 1〜6 の整数のみ対応）。

## 開発

```bash
npm install
npm run dev       # 開発サーバー
npm run validate  # 出題データの検証
npm run build     # 本番ビルド（dist/）
npm run preview   # ビルドの確認
```

## Cloudflare Pages へのデプロイ

このリポジトリを接続して、以下を設定するだけです。

| 設定 | 値 |
| --- | --- |
| Framework preset | Vite |
| Build command | `npm run build` |
| Build output directory | `dist` |
| Node.js version | 20（`.nvmrc` で指定済み） |

## 技術メモ

- React 18 + Vite 5 + Tailwind CSS 3
- 学校の古い iPad（iOS/iPadOS 12 以降の Safari）でも動くよう `@vitejs/plugin-legacy` を使用し、ソースコードでは Optional Chaining（`?.`）等の新しい構文を使っていない（element-quiz と同じ方針）
- ベスト記録は `localStorage` に保存（サーバー不要の静的サイト）
- 効果音なし・タップ操作のみ（授業での一斉使用を想定）
