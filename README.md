# 化学反応式マスター

中学2年生向けの化学反応式トレーニングゲーム。iPad での使用を想定し、全モードにタイムアタック（グレード評価 SS/S/A/B/C・端末内ベスト記録・復習機能つき）を搭載しています。

## モード

| ステップ | モード | 内容 |
| --- | --- | --- |
| STEP1 | 化学式マッチ | 物質名 ⇔ 化学式の対応づけ（4択 × 20問）。基本（中2頻出）／チャレンジ（中3・発展） |
| STEP2 | 係数バランス | 反応式の係数を入力してつり合わせる（10問）。基本＝空欄は1カ所だけで残りの係数は印字済み（中2の式）／チャレンジ＝すべての係数を入力（全収録式から出題） |
| STEP3（裏） | ○×ジャッジ | 表示された反応式が正しいか瞬時に判定（20問）。ミスは＋5秒ペナルティ |
| STEP4（裏） | 組み立てラボ | 実験の説明文から反応式をまるごと組み立てる（5問）。**まず物質カードを左辺・右辺にすべて並べ、そろってから係数を入力する**2段階の流れ（物質が欠けている間は係数欄と数字キーが無効） |

STEP3・STEP4 は**裏モード**：STEP1・STEP2 の全4モード（化学式・係数それぞれの基本／チャレンジ）で S ランク以上のベスト記録をとると解放されます。それまではカードは表示されるもののタップしても反応しません。解放条件を満たした瞬間の結果画面に「裏モード解放！！」のバナーが出て、ホームのバッジが STEP3/4 → 「裏モード」に変わります（遊び方モーダルに解放条件のヒントあり）。

学習支援の仕掛け：

- 係数を間違えると「原子数チェック」パネルが出現し、左辺：右辺の原子数が元素ごとにライブ表示される
- つり合っていても最簡整数比でない場合（例 4H₂O → 4H₂ + 2O₂）は専用メッセージで再挑戦を促す
- 正解時は係数1を省略した正式な書き方で完成式を表示
- 結果画面に「間違えた問題」の一覧（正しい式つき）と復習モード（復習では選択肢の並びも再シャッフル）
- 結果画面に「次のランクまであと○秒」の目標表示

ゲームの気持ちよさ：

- 連続正解でコンボ🔥が伸び、結果画面に最大コンボ・ノーミス達成バッジを表示
- 正解演出（約1秒）の間はタイマーが停止。落ち着いて完成した式を確認できる（タイムは純粋な解答時間で競う）
- 効果音つき（正解・ミス・カウントダウン・ファンファーレ・裏モード解放）。**初期状態は OFF**（静かな授業を想定）。ホーム右上のボタンで ON にでき、設定は端末に保存
- ○×ジャッジのミスは＋5秒ペナルティ（演出中のタイマー停止とあわせて、2択の連打では高ランクが出ないように調整）
- PWA メタ・マニフェスト対応：iPad の Safari で「ホーム画面に追加」すると全画面のアプリとして起動できる

## 収録データ

「中学範囲で頻出の化学反応式」資料をもとに、イオン反応式（電荷 ⁺/⁻ や e⁻ を含むもの・電池の半反応式）を除いた 44 反応式・57 物質を収録。

- 基本＝中2「化学変化」（化合・燃焼・分解・電気分解・還元）17 式
- チャレンジ＝気体の発生・中和・有機物の燃焼など 27 式
- 資料の「3Fe＋2O₂ → Fe₂O₃」は係数がつり合わないため、正しい「3Fe＋2O₂ → Fe₃O₄（四酸化三鉄）」に修正して収録

### 問題の追加・編集

`src/data.js` だけを編集すれば OK です。

```js
// 物質： f=化学式（ASCII表記）, name=物質名, q=化学式マッチの出題レベル(1/2/0)
{ f: "Ca(OH)2", name: "水酸化カルシウム", q: 2 },

// 反応式： lv=1(基本)/2(チャレンジ), jd=○×ジャッジ対象, bd=組み立て対象
eq("cu_o2", 1, "酸化", "銅を空気中で加熱すると、酸化銅ができる",
  [[2, "Cu"], [1, "O2"]], [[2, "CuO"]], { jd: true, bd: true }),
```

**説明文（第4引数）の書式**：`〈反応物〉を〈操作〉すると、〈生成物〉ができる（発生する／分解する）`

生成物は必ず日本語名で書き、`SUBSTANCES` の `name` と一致させてください。組み立てラボでは生徒がこの物質名を手掛かりにカードを探すため、名前がずれていると問題が解けなくなります。

編集後は `npm run validate` で以下を自動チェックできます（係数は 1〜6 の整数のみ対応）。

- 全反応式のつり合いと最簡整数比
- 反応式に使った化学式が物質データに登録されているか
- 説明文が上記の書式になっていて、**生成物の名前がすべて書かれているか**

## 開発

```bash
npm install
npm run dev       # 開発サーバー
npm run validate  # 出題データの検証
npm run build     # 本番ビルド（dist/）
npm run preview   # ビルドの確認
```

## Cloudflare Pages へのデプロイ

このリポジトリを接続して、以下を設定するだけです。

| 設定 | 値 |
| --- | --- |
| Framework preset | Vite |
| Build command | `npm run build` |
| Build output directory | `dist` |
| Node.js version | 20（`.nvmrc` で指定済み） |

## 技術メモ

- React 18 + Vite 5 + Tailwind CSS 3
- 学校の古い iPad（iOS/iPadOS 12 以降の Safari）でも動くよう `@vitejs/plugin-legacy` を使用し、ソースコードでは Optional Chaining（`?.`）等の新しい構文を使っていない（element-quiz と同じ方針）
- ベスト記録は `localStorage` に保存（サーバー不要の静的サイト）
- タップ操作のみ。効果音は WebAudio 合成音で初期 OFF（授業での一斉使用を想定）
- 文言は高校生・大人にも通用するトーンで統一（「基本」「正解」など漢字表記）
